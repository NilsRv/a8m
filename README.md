# A8M • All Hate’m

Site vitrine du collectif A8M : présentation, équipe Rocket League et archives visuelles.

## Stack

HTML, CSS et JavaScript, avec Vite et Lenis pour le défilement fluide.

## Lancer le projet

Avec Node.js et npm installés :

```sh
npm ci
npm run dev
```

Ouvrir l’adresse locale indiquée dans le terminal.

## Build

```sh
npm run build
```

Les fichiers prêts à héberger sont générés dans `dist/`. Pour prévisualiser le build localement :

```sh
npm run preview
```

## Structure

```text
index.html        Contenu de la page
src/main.js       Interactions et animations
src/style.css     Styles et responsive
public/           Images et polices
```
